# Moodium

Moodium 是面向 Apple Vision Pro 的空间交互体验项目。通过感官袋按压、情绪记录、现实房间探索、点云世界和心愿风铃，探索空间计算与日常情绪表达的结合。

## 体验内容

- 自由、节奏、呼吸三种按压模式，以及可调节的交互进度速度。
- 贴纸识别与手动选关、尺寸校准、开机动画与重播。
- Moodi 角色陪伴、手部交互、糖果雨和花草雨。
- 水银时空之门、沉浸式点云世界与心愿风铃书写和保存。

进度达到 100% 后，时空之门在交接流程结束后自动展开，用户可以自行关闭。

## 打开工程

1. 使用 Git LFS 获取大文件，执行 `git lfs install`，克隆仓库后执行 `git lfs pull`。
2. 使用 Unity 6000.0.30f1 打开工程，等待 Package Manager 安装依赖。
3. 开发环境使用 URP 17.0.3、PolySpatial 2.4.3 和 visionOS。打开 `Assets/ARTnGAME/Meshing 1.unity` 主场景。
4. 在具备 visionOS 支持的编辑器与 Xcode 环境中检查 XR 设置、设备权限和签名，再构建到 Apple Vision Pro。

仓库包含场景、预制体、模型、贴图、字体、音频、视频、点云及项目配置。设备效果依赖空间扫描、手部追踪和实际运行环境。

## 实现与来源

Moodium 的体验流程、按压计分、空间交互集成和心愿记录结合 Unity、PolySpatial 等工具构建。部分模型、特效、音效、字体和材质来自第三方，部分开发工作使用 AI 辅助。第三方来源与许可范围见 [THIRD_PARTY.md](THIRD_PARTY.md)。
